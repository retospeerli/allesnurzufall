# Alles nur Zufall? – Würfelexperiment

Eine eigenständige Browser-App für GitHub Pages, ohne Bibliotheken oder Server. 

20 Kinder würfeln unabhängig mit einem fairen sechsseitigen Würfel. Bei 20 und 100 Würfen wird jeder Wurf pro Kind angezeigt, bei 1’000 und 10’000 Würfen werden die Würfe in kleinen Paketen live ausgewertet. Tabelle und Diagramm verwenden dieselben gezählten Ergebnisse. Das Diagramm kann auch einzelne Kinder, Prozentwerte und die theoretische Erwartung anzeigen.
